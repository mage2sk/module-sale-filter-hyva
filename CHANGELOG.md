# Changelog

All notable changes to this extension are documented here. The format

## [1.1.1] - 2026-10-03

### Fixed
- The Yes and No options of the Sale Status filter on Hyva pages are now 44px tall, so they are easy to tap on phones and tablets.

### Added
- Unit tests for the configuration reader, the filter renderer block, both templates and the module configuration files.
